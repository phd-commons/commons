# Security

Commons holds research data that can include ethics-protected material. Please report vulnerabilities privately
through GitHub's "Report a vulnerability" (Security tab), not in public issues.

Of particular interest: any path by which RESTRICTED material could reach a cloud provider, the MCP server, a
backup or a log; ways to make the portal reachable beyond the local machine; and injection through ingested
documents into prompts or into the portal's HTML.
