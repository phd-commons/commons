# Worked example: early-career teachers in remote schools (fictional)

An invented thesis in education, built around interviews, to show Commons in qualitative work. It is not anyone's
real project.

Interview recordings go into `inbox/restricted/`. They are transcribed locally, stay RESTRICTED, and are linked to
the propositions like any other source. The rivals (planned short stays, leadership turnover) are the accounts an
examiner would raise; the thesis board shows whether the interviews bear them out.

```
commons init ~/commons-teaching --preset ollama
cp thesis.yaml sources.yaml ~/commons-teaching/
```

See docs/data-and-ethics.md before adding any real interview data.
