# Analyses

Field-specific tests of your thesis live here, one folder per module: `analyses/<code>/run.py` plus a README that
states the test before it is run. `commons analysis` lists them; `commons analysis <code>` runs one.

Two built-ins work in every project: `evidence_balance` (claims for and against each proposition) and
`literature_by_year`. `sources_by_kind` below is a worked example of the module contract.
